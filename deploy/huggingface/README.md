# MetaPy: transparent meta-analysis

Upload your extraction sheet (CSV or Excel). MetaPy finds the analyses your data can support, derives missing
statistics with cited formulas (and shows every calculation), runs the meta-analysis, and exports tables,
figures and a report (Word, Excel, PDF, HTML).

- Your file is processed in memory only while you use the page; nothing is stored on this server or shared with other users.
- Use de-identified, aggregate study data only.
